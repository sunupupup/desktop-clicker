# 单按钮随机点击行为测试器

这是一个用于自有 App 行为分析的本地 Windows 演示项目，使用 Python 标准库和 Tkinter，不需要额外安装 GUI 依赖。

## 启动

安装了 Python 3.10 或更高版本后，在项目根目录运行：

```powershell
python -m src.clicktrace
```

程序会打开两个窗口：

- **被测 App**：窗口里只有一个按钮。手动点击和模拟点击都会更新按钮计数，并记录到控制台。
- **随机点击测试控制台**：设置点击数量、随机种子、间隔范围和双击簇参数；在画布上拖动蒙板，或拖动右下角手柄调整大小；启动/停止随机模拟；查看并导出行为记录。

## 随机行为

- 第一条模拟点击立即触发，后续点击在“间隔最短/最长”范围内随机等待。
- “双击簇概率”控制长间隔之后是否再附加一次短间隔点击；设为 `0` 会关闭双击簇。
- 坐标在蒙板区域内按整数像素随机选择。相同设置和随机种子会得到相同的坐标及时间间隔序列。
- 点击总数最多为 10000；最短间隔至少为 0.1 秒。

## 导出数据

JSON 文件包含 `metadata` 和 `events`。CSV 文件第一行以 `# metadata=` 保存配置，后续每行是一条事件。

事件列包括：`scenario`、`seed`、`sequence`、`elapsed_ms`、`x`、`y`、`event_type`、`origin`。

- 模拟事件的坐标相对于控制台蒙板画布。
- 手动事件的坐标相对于被测按钮。
- `origin` 标记为 `simulated` 或 `manual`。
- 随机种子和参数会写入模拟事件及导出元数据，方便把检测结果对应回生成配置。

## 输入范围

模拟器只在本程序的被测按钮上生成 Tk 按下/释放事件，并在本地记录合成事件。它不会向操作系统注入鼠标/键盘事件，不会操作浏览器、其他桌面窗口或外部服务。
